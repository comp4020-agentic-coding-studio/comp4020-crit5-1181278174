Colophon Source
COMP4020 Agentic Coding Studio · Crit 5 · SONG XianShuo · 2026

Vanilla TypeScript, Canvas 2D and Vite. No framework, no images, no audio: every pixel on the canvas is drawn at run time, and the link-preview card is a screenshot of the simulation running headlessly. Every arena after the first is generated from a seeded RNG, so a run can be named by its number.
